================================================================================
                    🔧 QUICK FIX - PERMISSION ERROR
================================================================================

ERROR: "Missing or insufficient permissions" when clicking login

SOLUTION: 5 Simple Steps (10 minutes total)

================================================================================
STEP 1: Update Firestore Security Rules (2 min)
================================================================================

1. Go to: Firebase Console → Firestore Database → Rules
2. Delete all existing rules
3. Paste this:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /admins/{userId} {
      allow read, write: if true;
    }
    match /{document=**} {
      allow read, write: if false;
    }
  }
}

4. Click PUBLISH
5. Wait 30 seconds

✅ DONE!

================================================================================
STEP 2: Create Firebase Auth User (1 min)
================================================================================

1. Go to: Firebase Console → Authentication → Users
2. Click "Create user" button
3. Enter:
   - Email: admin@mompulse.com
   - Password: admin_mompulse
4. Click "Create user"

✅ DONE!

================================================================================
STEP 3: Get User UID (1 min)
================================================================================

1. Go to: Firebase Console → Authentication → Users
2. Click on admin@mompulse.com
3. Copy the "User UID" (looks like: abc123def456...)
4. Save it - you'll need it next

✅ DONE!

================================================================================
STEP 4: Create Firestore Document (2 min)
================================================================================

1. Go to: Firebase Console → Firestore Database
2. Click "Create collection"
3. Collection name: admins
4. Document ID: Paste the UID from Step 3
5. Click Save
6. Add these fields:
   - email: admin@mompulse.com
   - role: super_admin
   - displayName: Super Admin
   - status: active
   - createdAt: (current timestamp)
7. Click Save

✅ DONE!

================================================================================

================================================================================

2. Go to: http://localhost:3000
3. Login with:

   - Password: admin_mompulse
4. You should see the dashboard!

✅ DONE! 🎉
